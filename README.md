# کرونو (Chrono)

یک برنامه تحت وب سبک، ماژولار و کارآمد برای مدیریت زمان و پیگیری تسک‌ها که با PHP، جاوااسکریپت خام (Vanilla JS) و Tailwind CSS توسعه یافته است.

## قابلیت‌ها

- **ثبت و مدیریت نوبت‌ها:** شروع، پایان و ویرایش نوبت‌های کاری به همراه توضیحات تسک.
- **گزارش‌گیری:** نمایش آمار ساعت‌های کاری روزانه، هفتگی و میانگین با قابلیت خروجی CSV و حالت چاپ.
- **کنترل دسترسی نقش‌محور:** تفکیک نقش‌های مدیر (Manager) و همکار (Partner) با امکان اعطای دسترسی مشاهده گزارش سایر کاربران به‌صورت اختصاصی.
- **سیستم لاگ دو لایه:** ذخیره فایل‌محور لاگ‌های خطایابی فنی و لاگ فعالیت‌های کاربران.
- **پشتیبان‌گیری و بازیابی:** خروجی و ورودی داده‌های نوبت‌های کاری کاربران در قالب فرمت JSON.

## پیش‌نیازها

- وب‌سرور: Apache، Nginx یا LiteSpeed
- نسخه PHP: حداقل نسخه 8.0 یا بالاتر (افزونه `pdo_mysql` برای MySQL یا `pdo_sqlite` برای SQLite؛ `mbstring` توصیه می‌شود)
- پایگاه‌داده: MySQL 5.7+ / MariaDB 10.3+ یا SQLite 3

## نصب و راه‌اندازی

### ۱. بارگذاری فایل‌ها
تمام فایل‌های پروژه را در ریشه هاست یا پوشه مدنظر خود (مانند `public_html`) آپلود کنید.

### ۲. تنظیم پایگاه‌داده
یک کپی از فایل نمونه تنظیمات با نام `config.php` ایجاد کنید:
```bash
cp config.example.php config.php
```

سپس `config.php` را باز کرده و درایور و مشخصات پایگاه‌داده را وارد کنید.

برای MySQL:
```php
define('DB_DRIVER', 'mysql');
define('DB_HOST', 'localhost');
define('DB_NAME', 'your_database_name');
define('DB_USER', 'your_database_user');
define('DB_PASS', 'your_database_password');
define('DB_CHARSET', 'utf8mb4');
```

برای SQLite (مناسب تست و استقرارهای کوچک):
```php
define('DB_DRIVER', 'sqlite');
define('DB_SQLITE_PATH', __DIR__ . '/data/chrono.sqlite');
```

نکته: جدول‌های پایگاه‌داده و کاربر مدیر اولیه در نخستین بازدید از سایت به‌طور خودکار ساخته می‌شوند.

> فایل `config.php` حاوی اطلاعات حساس است و در `.gitignore` قرار دارد؛ آن را commit نکنید.

### ۳. مجوز دسترسی فایل‌ها (Permissions)
سطوح دسترسی زیر را روی سرور اعمال نمایید:

- پوشه‌ها: `755`
- فایل‌ها: `644`
- پوشه‌های `logs/` و `data/`: دسترسی قابل نوشتن (`755` یا `775`)

### ۴. اطلاعات ورود اولیه
سایت را در مرورگر باز کنید و با نام کاربری `admin` وارد شوید.

رمز عبور اولیه به‌صورت تصادفی ساخته شده و در فایل `logs/INITIAL_ADMIN_PASSWORD.txt` ذخیره می‌شود (مگر آنکه مقدار `INITIAL_ADMIN_PASSWORD` را در `config.php` تعیین کنید). این رمز موقت است و در **نخستین ورود**، سامانه شما را ملزم به تغییر آن می‌کند. پس از تغییر رمز، فایل `INITIAL_ADMIN_PASSWORD.txt` را حذف کنید.

سیاست رمز عبور: حداقل ۱۰ کاراکتر، شامل حداقل یک حرف و یک عدد (حداکثر ۷۲ کاراکتر).

### ۵. نکات امنیتی مهم
- پوشه‌های `logs/`، `includes/` و `data/` فقط با `.htaccess` محافظت می‌شوند که روی **Apache** کار می‌کند. روی **Nginx/LiteSpeed** باید دسترسی مستقیم به این پوشه‌ها و به `config.php` را در کانفیگ وب‌سرور مسدود کنید؛ بهتر است `logs/`، `data/` و `config.php` را بیرون از ریشه وب قرار دهید.
- اگر پشت یک پراکسی/لودبالانسر مطمئن هستید، `TRUST_PROXY` را در `config.php` برابر `true` قرار دهید تا تشخیص HTTPS از هدر `X-Forwarded-Proto` انجام شود. در غیر این صورت آن را `false` نگه دارید.
- برنامه از توکن CSRF و محدودسازی نرخ تلاش‌های ناموفق ورود استفاده می‌کند؛ برای عملکرد صحیح، پوشه `logs/` باید قابل نوشتن باشد.
